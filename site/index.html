01 · Principles

Few tools. Each one answers a question.

Most Microsoft 365 servers mirror Graph: hundreds of tools, or a handful of generic ones that make the model learn Graph by heart. This one follows the questions people ask, and does the work Graph leaves to the caller.

01

One question, one tool

Depth is a parameter, never a second tool. get_message(include_thread), not three near-identical tools to choose between.

02

The server does Graph's homework

It resolves names to people and folders, expands recurring meetings, pages with an opaque cursor and cleans HTML in both directions.

03

Sending is two steps

The agent writes a draft; send_draft sends only a draft this server created, after the person confirms. At most 20 recipients, no distribution lists.

04

Files never pass through the model

Downloads and uploads go through signed links that live 15 minutes at most. The bytes stream through the server, not through the context window.

05

Other people's words are data

Mail, chats and documents written by others come back marked as data, not instructions. Hidden HTML is dropped before the model sees it.

06

Nothing that cannot be undone

No inbox rules, no forwarding, no other people's mailboxes, no hard delete. Mail goes to Deleted Items; files go to the recycle bin.

02 · How it fits

Your gateway signs in. The server holds nothing.

An MCP gateway does OAuth for each person and forwards their Graph token on every request. The server stores no tokens; bytes move through signed links the agent's sandbox can fetch.

04 · How it is tested

A rule the code can break silently is a defect in the tests.

200

Refusal evidence

Every "must refuse" row names its test. A script removes each guard in turn and requires that test to fail.

69

Mutations

Each safety rule is deleted from the code one at a time; some test has to go red every time.

16,000

Token budget

The catalogue is measured on every pull request and refused above the limit: per area and per tool too.

37

Live probes

The same tools against a real Microsoft 365 tenant with two people, measuring what Microsoft's documentation leaves unsaid.

05 · Run it

One container. Your gateway.

  • Streamable HTTP, stateless: one person's Graph token per request.
  • Switch areas on and off; narrow them per person with a header.
  • Optionally limit which domains mail and invitations may reach.
# build and run
docker build -t m365-mcp .
docker run -p 8000:8000 -p 8001:8001 \
  -e M365_LINK_SIGNING_KEYS=<base64url, 32+ bytes> \
  -e M365_LINK_ENCRYPTION_KEYS=<base64url, 32+ bytes> \
  -e M365_LINKS_BASE_URL=https://<public host for :8001> \
  m365-mcp

# :8000/mcp      the MCP endpoint (Authorization: Bearer <Graph token>)
# :8001/d, /u    signed download and upload links
